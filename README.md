### Что необходимо сделать:
#### – Напечатать в столбик все значения 2^n
#### – Организовать ввод пользователем степени n
#### – Сформировать запись каждого значения в виде 2^n = значение, которое будет выровнено по правому краю
#### – Также исследовать вычисление степеней для 3 разных типов данных:
#### int
#### unsigned int
#### long long
#### – Зафиксировать момент переполнения и составить таблицу
### Таблица с полученными результатами:
| Тип данных | Последняя корректная степень | Результат | Что происходит дальше |
| --- | --- | --- | --- |
| int | 30 | 1073741824 | при n = 31 число становится отрицательным (-2147483648), а дальше превращается в 0 |
| unsigned int | 31 | 2147483648 | при n>=32 число превращается в 0 |
| long long | 62 | 4611686018427387904 | при n = 63 число превращается в -9223372036854775808, а дальше в 0 |
### Вопросы:
#### Как изменился диапазон положительных значений при переходе от int к unsigned int?
#### – Диапазон положительных значений увеличился в 2 раза, так как название unsigned означает освобождение старшего разряда от роли знакового бита 
#### Что изменилось при переходе от unsigned int к long long?
#### – Объем памяти увеличился с 4 байт до 8 байт, что позволило вычислять степени до 2^62
#### Почему увеличение размера типа позволяет вычислить больше степеней двойки?
#### – Так как каждое умножение на 2 сдвигает конечное число на один бит влево, а чем больше развязность, тем больше бит доступно до переполнения 
#### Что происходит с результатом после выхода за диапазон типа?
#### –  У unsigned int числа после 32 степени обнуляются, а у long long и int сначала числ становятся отрицательными, а после нулевыми
